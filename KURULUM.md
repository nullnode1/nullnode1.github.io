# nullnode1.github.io Docsify kurulum

Bu paket doğrudan `nullnode1/nullnode1.github.io` için ayarlanmıştır.

1. Depoyu klonla: `git clone https://github.com/nullnode1/nullnode1.github.io.git`
2. Paket içindeki dosyaları deponun köküne kopyala (README.md dahil).
3. `git add . && git commit -m "Docsify blog kurulumu" && git push origin main`
4. GitHub > Settings > Pages > Deploy from a branch > main > /(root) seç.

Site: https://nullnode1.github.io/

Yeni yazılar `posts/YYYY-AA-GG-yazi-basligi.md` biçiminde eklenir.
